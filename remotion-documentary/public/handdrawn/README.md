# Hand-drawn long-form assets

Put the canonical editorial stills for the long-form documentary here.

Use a numeric prefix to define exact shot order:

- `01_A_5-second_hand-drawn_ani.png`
- `02_A_5-second_hand-drawn_ani.png`
- `03_A_5-second_hand-drawn_ani.jpg`
- ...

Supported formats: PNG, JPG/JPEG, WebP.

The leading number is the only ordering key. Do not rely on filesystem order.
Do not put pink/generated test clips in this directory.

Run `npm run assets:prepare` from `remotion-documentary` after changing this folder.
