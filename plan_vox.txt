The finance engine stays untouched and both can render from the same episode file.

3. src/vox/scenes.tsx — NEW file (generic Vox modules)
One VOX_MODULES record — same contract as MODULES (({dur}) => JSX), so no per-episode JSX ever:
kinetic    → big KineticText phrase (the hook/claim words slam word-by-word)
doodle     → roughjs circle/underline over footage while a word lands
icon       → LineIcon + label pop (mechanism step cards)
chart      → InkChart draws in (compounding, growth)
map        → country draws in (phase 3)
footage    → full-bleed archival clip, kinetic caption overlay
A script beat becomes: { module: "kinetic" | "doodle" | ... } — the same module field parse-script.mjs already emits.
