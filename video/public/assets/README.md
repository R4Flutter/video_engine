# Supplied Asset Library

Put generated assets here. The editor is intentionally asset-first.

```text
assets/
  subjects/       transparent hero subjects / products / people
  archive/        historical and documentary images
  documents/      filings / receipts / screenshots / evidence
  graphics/       maps / timelines / charts / diagrams
  backgrounds/    contextual environment plates
  logos/          approved transparent brand marks
```

Use the stable IDs and paths from `prompts/asset-manifest.template.json`.

The director decides framing, crop, camera and sequencing. It should not silently replace a missing supplied asset with random stock media.
