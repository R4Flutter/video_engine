# LOGOS — PRODUCTION-GRADE SOURCE SPECIFICATIONS

These are not AI-generation targets. Prefer official brand assets, approved press/media kits, trademark-safe public sources or repository-provided source files. Never ask an image model to redraw a recognizable logo when an original vector/raster source can be obtained. Normalize every logo after acquisition without altering the mark.

## Global requirements
- Deliver as PNG with real alpha, square canvas 2048×2048 unless brand source requires another ratio.
- Preserve official proportions, color values, spacing and symbol geometry.
- No recreated or hallucinated lettering.
- Remove only unwanted background; do not remove internal transparent counters or official negative space.
- Keep a consistent optical scale across the logo set so equal pixel dimensions do not make one mark appear artificially huge.
- Do not add glow, drop shadow, bevel, 3D effects or recoloring.
- Validate edges at 400% zoom for halos and matte contamination.
- Store source URL/license note in the asset manifest.
