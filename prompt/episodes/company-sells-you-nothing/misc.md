# MISC / UTILITY ASSETS — PRODUCTION-GRADE PROMPTS

All assets are independent transparent PNGs at 2048×2048 unless noted. They are utility layers, so edges must remain crisp, alpha must be genuine and there must be no baked background, checkerboard, shadow box or watermark. Utility graphics should be deliberately simpler than the main editorial imagery so they animate cleanly.

## `cursor-white.png`
00:55 · P0 · 2048×2048 · REAL ALPHA

**Master prompt:** Create a single clean desktop mouse cursor arrow as a transparent cutout. Shape should be a standard white arrow pointer with a very subtle 1–2px dark edge for visibility over pale screens, physically crisp but not pixelated, slight anti-aliased edge, no glow. Center the cursor diagonally at approximately 35–40 degrees, leaving generous transparent padding. The cursor must look like a real operating-system pointer rather than a cartoon hand. No shadow except the minimal outline required for contrast.

**Negative:** hand cursor, emoji, oversized pointer, neon glow, drop shadow box, background, multiple cursors, watermark.

## `paper-shadow.png`
All evidence inserts · P2 · 2048×2048 · REAL ALPHA

**Master prompt:** Create a soft realistic contact shadow for a floating document composite. Shape is a horizontal diffuse rectangular footprint with slightly darker density immediately beneath a page edge and rapidly feathering transparency outward. Neutral charcoal-gray shadow with low opacity, no visible page or background. The alpha falloff must be smooth enough for compositing over both dark and warm paper plates. Do not create a full vignette. Keep the shadow soft and physically plausible, as though one sheet of paper is 3–5mm above a desk.

**Negative:** hard rectangle, black box, drop-shadow UI effect, page visible, background, halo, excessive opacity.
