# Episode 01 — The Company That Sells You Nothing

This folder is the production asset packet generated from the revised ~19-minute script.

Generation order:
1. `evidence.md` — source captures first.
2. `archive.md` + `logos.md` — historical/brand references.
3. `subjects.md` + `backgrounds.md` — compositing library.
4. `ui-mockups.md` + `graphics.md` — designed visual information.
5. `broll.md` — short motion inserts.
6. `manifest.md` — deterministic editor handoff.
7. `sources.md` — fact/source lock.

Nothing here is a promo sheet. Every entry is an independent production target.

## Priority
- P0 = required for first cut.
- P1 = strongly recommended for polish and retention.
- P2 = optional coverage / alternate cut.

## Source modes
- SOURCE_CAPTURE = use the original public document / filing.
- GENERATED_STILL = generate from the production prompt.
- STOCK_BROLL / GENERATED_VIDEO = real-looking motion footage.
- LOGO_SOURCE = use official logo/vector source where appropriate.
- UI_RECONSTRUCTION = recreate the interface visually; overlay final copy in the renderer.

## Hard stop
This stage stops after script + prompt generation + manifest. Do not render the final episode or generate the media automatically.
