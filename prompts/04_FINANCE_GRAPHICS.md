# Prompt 04 — Finance / Data Graphic Plate

Use when a statistic, relationship, timeline or mechanism is better communicated as a graphic than as footage.

```text
Create a premium editorial data-visualization plate explaining: [EXACT VERIFIED FACT / RELATIONSHIP].

Visual form: [BAR COMPARISON / LINE CURVE / TIMELINE / FLOW DIAGRAM / STACK / MAP].

Data to encode exactly:
[PASTE VERIFIED DATA]

Composition: one dominant visual argument, large readable labels, strong hierarchy, generous negative space. Designed so the editor can animate individual components separately if needed.

Style: serious business journalism, precision information design, flat vector geometry, charcoal/cream foundation with ONE accent color. Grid alignment must be mathematically clean. Labels must be short and legible on a phone.

No 3D bars, no glossy dashboards, no random percentages, no decorative charts, no fake axes, no invented categories, no gradients, no excessive icons.

Export as a clean graphic plate with no captions or narration text baked into the artwork unless those words are explicitly part of the supplied data.
```
