# Prompt 10 — Variant Set for One Subject

Generate a coherent set of reusable assets for the SAME subject so the editor can cut between them without identity drift.

```text
Using the exact same [SUBJECT] reference, create a coherent editorial asset set:

A. HERO LEFT — subject facing / weighted toward left, transparent background.
B. HERO RIGHT — mirrored composition, subject facing / weighted toward right, transparent background.
C. MEDIUM — subject from waist/half/full depending on object, transparent background.
D. CLOSE DETAIL — distinctive detail that proves identity, transparent background.
E. CONTEXT WIDE — subject in its real environment, 16:9.
F. PAYOFF HERO — stronger scale/presence, still realistic, transparent background.

Maintain identical identity, proportions, colors, materials and markings across every variant. The variants must look like photographs from the same production rather than six unrelated generations.

No text, subtitles, watermark or decorative frame. Use identical lighting logic and neutral editorial grade.
```

Append `00_BASE_STYLE_LOCK.md`.
